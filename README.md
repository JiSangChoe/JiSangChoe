## 👨‍💻 About Me

> **Beyond writing code, building systems that make a difference.**
>
> 단순히 코드를 작성하는 것을 넘어, 실질적인 가치를 만드는 시스템을 개발합니다.

Java와 Spring Boot를 기반으로 기업 업무시스템을 개발하고 운영하는 개발자입니다.

비즈니스 요구사항을 분석하여 효율적인 시스템으로 구현하는 데 관심이 있으며,
백엔드 개발부터 웹 인터페이스, 데이터베이스, 시스템 운영까지 폭넓은 경험을 쌓고 있습니다.

최근에는 AI RAG 시스템 연동과 업무 자동화를 통해 기존 시스템의 확장 가능성을 탐구하고 있습니다.

- 💻 **Main Focus** : Backend & Enterprise Web Development
- 🔧 **Experience** : System Development, Maintenance & Automation
- 🌱 **Currently Learning** : Python, AI, RAG & Information Security
- 🎯 **Goal** : 안정적이고 확장 가능한 시스템을 설계하는 개발자
